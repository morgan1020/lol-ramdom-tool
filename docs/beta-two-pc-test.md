# 1.5.0-beta.2｜兩台電腦測試

1. 兩台 Windows x64 電腦各自下載並執行安裝版或免安裝版。開啟 App 後，到右上角「設定」，確認左下角顯示 **v1.5.0-beta.2**。如果這台已經裝了舊版，請先關閉舊版；安裝版和免安裝版共用同一份本機資料。
2. 兩人登入不同的 LoL 帳號，加入同一個可選分路的組隊大廳（建議積分雙排大廳），先不要開始排隊。兩端及同步服務都須支援 beta.2 的免準備抽籤。A 在 App 選「多人房間 → 建立房間」。B 選「多人房間 → 加入房間」，再按「加入目前隊伍」；找不到時，A 點房碼複製完整邀請，B 貼到「邀請或房碼」後申請加入。
3. A 核准 B，點玩家卡片指定一人的主位。核對兩端皆顯示「App 在線 2 人」，A 直接按「開始抽籤」。確認兩台 App 的整隊結果一致，且兩邊的 LoL 客戶端都套用了自己抽到的分路。沒有加入 App 的隊友需手動調整。
4. 首輪先選「不自動傳送」，確認照樣能抽籤及複製結果。接著由 A 從左下角 Discord 選單開啟「管理 Webhook」，新增專用測試頻道的 Webhook，回到選單選取該頻道。A 按「重新抽籤」，確認兩台結果仍一致，Discord 只收到一則整隊結果。切回「不自動傳送」再抽一次，確認沒有新訊息。
5. 選測：B 關閉「自動套用我的分路」，短暫斷線再重連，確認開關保持關閉。A 再抽一次，B 應收到新結果且自己的 LoL 分路不變。測完由 A 切回「單人」並確認關房，確認 B 收到關房狀態。

測試包內含房主指定的同步服務位址。完整邀請請私下分享，Discord Webhook 由房主自行設定。回報問題時請附上版本、做到第幾步，以及兩台 App／LoL／Discord 的實際結果；截圖請遮住房碼、完整邀請與 Webhook。
